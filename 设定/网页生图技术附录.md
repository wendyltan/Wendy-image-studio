# 网页生图技术附录

版本：v1.2
更新时间：2026-09-09
适用范围：通过 Codex/GPT 客户端内嵌浏览器，在用户已登录的 ChatGPT 网页中生成或编辑图片。

本文件只记录易变化的网页操作与模型名称核验方法。故事策划、角色设定、连续性、拼接和验收仍以《温蒂日常小红书漫画工作指引》为准。

## 一、默认渠道与切换边界

- 正式生图默认使用客户端内嵌浏览器打开用户的 GPT 会话，不直接调用 Codex `imagegen` 服务，也不要求另开外部 Chrome。
- 开始一批正式生图前，只用一张低风险测试图验证登录、上传、生成和下载链路；线路测试不计入正式成稿。
- 若内嵌浏览器断开、页面无法打开、登录失效或网页渠道连续失败，保留提示词与页面状态并向用户汇报。只有用户明确同意后，才改用外部浏览器或其他渠道。

## 二、已验证的执行流程

以下流程于2026-08-16在用户已登录的 ChatGPT 网页中跑通：

1. 使用客户端内嵌浏览器打开 `https://chatgpt.com/`，确认账号已登录并进入本篇已有会话或新会话。
2. 上传参考图时，优先按顺序把本地图片写入内嵌浏览器剪贴板，再在输入框逐张粘贴；每张都要确认出现独立附件。文件选择器稳定时也可使用，但不得因文件选择器超时就放弃内嵌浏览器。
3. 附件齐全后再一次性提交冻结的单分镜提示词。逐张说明其角色：身份参考、环境参考、物件参考或待编辑原图。
4. 页面显示“正在生成图片”或同等状态时等待完成，禁止重复提交。
5. 页面显示“已生成图片”后，先检查可见结果，再获取当前页面加载的原始 PNG；网页截图不能代替原始成稿。
6. 原图立即保存到本篇 `素材/` 并使用语义化版本名。若原图不是1080×1440但宽高比正确，保留原图，再无拉伸导出1080×1440 RGB PNG发布版。
7. 保留本次 GPT 会话，方便从图片“编辑”入口做单点修正。修正版使用 `-v2`、`-v3` 等版本名，不覆盖当前修改依据。

## 三、提交与恢复规则

- 每次网页提交只解决一个明确分镜或一项明确修改。
- 提示词必须包含页码或用途、目标比例、固定设定、附件角色、允许文字和禁止项。
- 网页超时或状态异常时，先检查会话、网页图片资源和目标 `素材/` 目录是否已经产出文件，再决定是否重试。
- 用户指出单点问题后，优先从当前图片的“编辑”入口继续；写清“只改变什么”和“必须保持什么”，修正版仍重新检查人物、肢体、文字、主题和尺寸。

## 四、图像模型名称核验

- 页面显示的聊天模型名称不等于底层图像模型名称。
- 产品名称与API模型标识必须分开表述；只有页面详情、生成记录或官方可核验证据直接暴露具体图像模型时，才能报告“已确认”。
- 图片尺寸、画风、速度或聊天模型名称均不能作为底层图像模型版本的证据。
- 页面和下载文件未暴露模型元数据时，应写：“本次通过 ChatGPT 网页图片生成功能完成，但具体底层图像模型未由页面披露。”
- 具体产品名称、开放范围和模型映射可能变化；需要对外确认时重新查阅当时的OpenAI官方说明，不在核心工作指引中长期固定版本结论。

## 五、技术附录维护

- 网页按钮名称、上传方式、下载能力或模型披露方式变化时，只更新本文件，不修改世界观。
- 更新后记录验证日期；未经实际跑通的替代流程不得标记为“已验证”。

## 六、温蒂创作室后台接入（2026-09-09）

温蒂创作室的新图片任务统一登记为 `provider=chatgpt-web-iab`。临时 CLI 子进程不再负责创建浏览器；一个专用 Codex 任务持有 IAB，Web 服务通过 `codex queue --thread` 向它投递作业。浏览器只能是 Codex IAB，禁止 `image_gen` 和外部浏览器。Codex 内的浏览器界面允许显示，但不会打开或接管用户的 Chrome、Edge 或 Safari。

每个作业以 `web-generation.json` 为事实来源：

```text
queued → ready → submitted → downloaded
                    └────────→ failed
ready 之前失败：submitted=false，可确认未提交
submitted 之后失败：submitted=true，结果未知，不自动重生
```

网页动作必须在同一个 Codex 回合内完成附件上传、唯一一次发送、等待和下载；回合结束可能清理 IAB 标签页，不能在 `ready` 后退出等待确认。用户在创作室中的确认动作通过 `worker-request.json.authorization` 持久化，后台不得重复询问。

原图优先通过页面下载事件取得；下载事件不可用时，可以使用 IAB 的 `pageAssets` 清单和 bundle 能力提取当前页面已加载的原始资源。必须使用清单中的 inventory ID 与图片 asset ID，取得本地资源包后再复制到指定输出路径，并以图像解码、尺寸、格式和 SHA-256 校验。截图、缩略图和程序重绘都不能代替原图。

2026-09-09 已用两张温蒂人设完成一次真实单格验证：唯一网页请求成功，原始 1497×1051 RGB PNG 已落盘并挂接，清单包含真实会话 URL、`submitted=true` 与 `state=downloaded`。后续局部编辑优先复用图片记录中的 `conversationUrl`；如果旧会话不可用，则把待编辑原图作为第一项附件建立新对话，仍只提交一次。
