# 温蒂创作室

双击上一级文件夹中的 **打开温蒂创作室.app**，浏览器会打开本地创作室。之后所有需求、方案确认、图片修改和成品下载都在网页完成。

1. 输入故事、页数和本篇特别要求。已有世界观和参考图会自动读取。
2. 查看完整逐页方案，可以直接输入修改意见。点击“方案确认，可以开始生图”。
3. 确认人物和主场景的两张样张，继续整篇制作。
4. 放大查看全部页面，通过验收后收下成品。可逐页保存、整套下载或打开本地文件夹。

网页地址：<http://localhost:4318>。只能从本机访问。浏览器关闭不影响已启动的制作；电脑睡眠或服务中断后会保留已完成内容，重新打开后可以继续。

作品在本目录的 `作品/<作品编号>/v<方案版本>/成品/`。每页是 1080×1440、RGB PNG。原始图、方案、冻结参考图、局部修订、验收记录与历史版本另外保存。应用不自动删除素材。

## 本地连接

由官方 Codex 命令行工具复用已有 ChatGPT 登录，调用其内置 image_gen 工具。认证由 Codex 自己管理，不复制登录凭据，不抓取浏览器 Cookie。没有向自制接口转发账号令牌，不使用 ChatGPT 网页自动点击。首次需要在 Codex 中登录，后续直接打开本应用。网络或账号额度不足会暂停，界面可重试。离线只能浏览已保存作品。

本地网站调用方式参考 [OpenAI 非交互运行文档](https://learn.chatgpt.com/docs/non-interactive-mode)。调用仍受当前账号的功能开放与使用额度约束。

用户本次明确允许内置生图或网页版 GPT，所以本应用采用已实测的内置生图路径；原工作指引里的网页默认渠道未被改写。创作方案和图像内容会发往当前账号使用的模型服务，本地保存并不代表离线生成。

## 工作流对应与边界

- 四份核心要求每次规划重新读取，冻结方案时保存要求快照和对应参考图。两张温蒂人设图必须同时带入；小林只有本篇明确勾选才允许引用。汤圆按本篇设置与剧情自然出场。
- 完整故事弧线、逐页分镜、动作、视线、表情、服装、光线、空间层次、逐字文案、提示词和四份连续性台账均由模型真实规划。改稿新建方案版本，必须重新确认。
- 先两张高风险样张，再逐格生成。原图即时落盘，逐格视觉校对；不合格自动修订一次，再失败即暂停，不无限重试。
- 按分镜实际比例生成，中文用本机中文字体确定性排版。拒绝明显比例错误；小于16%的边缘比例差只在预留安全区内裁切，不拉伸、不模糊填边。最终仍以完整肢体和关键物件验收为准。
- 正式图片逐格、逐页、全篇进行模型视觉检查，最终必须由用户在原始尺寸下核对人物、肢体、文字、连续性与噪点后收下。自动视觉检查不能保证发现全部画面问题，未完成检查的图片不进入成品目录。
- 噪点或人物漂移用内置图片编辑修正，重新校对；不把未处理图片自动标记成品。
- 当前内置排版提供全页、主副双格、主格加两格、三段蒙太奇、主格加三格；正文与时间标签放在独立的紧凑文字区，避免遮挡主体。对白带说话者，保持与旁白区分。
- 手机和车机内屏文字单独记录逐字内容和状态；原始生图保留空玻璃，后续由视觉模型定位内屏并生成确定性的中文透视排版脚本，处理圆角、手指遮挡和反光，再独立校对。无法可靠定位或验收未通过时暂停，不把平面截图浮贴作为完成。该复杂分支尚未以真实漫画内屏做端到端验收。
- 新增长期设定、把素材提升为标准参考、删除失败版本与公开发布均不自动执行；本应用专注创作与保存。

## 维护

Node.js 22.13+、已有 Codex 登录、本机 Python + Pillow、macOS STHeiti 字体。当前这台电脑的依赖已安装。

- `npm run dev`：页面开发预览，`npm run server`：本地服务。
- `npm run build`：打包为本地静态页面，`npm start`：运行本地服务。
- `npm test`：工作流、文件边界、排版和服务回归检查。
- 可通过 `WENDI_CODEX_BIN`、`WENDI_PYTHON` 显式指定本地工具。测试使用独立临时目录；生产作品目录默认固定在本应用中。
- 不要公开反向代理本服务；它只为受控的本地浏览器设计。
